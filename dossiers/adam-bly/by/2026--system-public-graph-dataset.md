# System Public Graph

## Abstract (only openly available portion)

The System Graph is a domain-agnostic, multi-scale graph with a scientifically-established finding as its atomic unit.

Updated daily, using AI, and with a patented approach, the System Graph extracts, grounds, and links findings from verified sources like peer-reviewed studies and expert-curated databases.

This generates millions of rich, quantitative relationships that cut across sources and fields from health, biology, climate, economics and beyond. It is a constantly growing, living representation of scientific knowledge.

The System Public Graph is an annual static snapshot of a subset of the System Graph. Its contents are derived only from open, publicly available sources.

The System Public Graph is made freely available for non-commercial use. It is designed to support researchers and developers across multiple disciplines, who need structured, machine-readable representations of scientific knowledge and relationships for analysis, modeling, and application development.

The System Public Graph will soon be made available in other formats with more frequent updates: check [System.com](https://www.system.com) for updates.
