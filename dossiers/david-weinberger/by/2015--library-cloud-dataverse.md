# Library Cloud

## Abstract (only openly available portion)

Catalog metadata++ about Harvard Library's collection + VIA images + Archival items. Total of about 17M items. Provides an API, which is documented at https://wiki.harvard.edu/confluence/display/LibraryStaffDoc/Library+Cloud . A overview is attached as the data file. Entry point for calls at http://api.lib.harvard.edu/v2/items . No authentication required for the calls.
