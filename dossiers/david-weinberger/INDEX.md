### What was searched and what is exhausted

**Joho the Blog (hyperorg.com) — enumerated completely, sampled deliberately.**
The blog's WordPress REST API returned **9,253 posts** spanning 2001-08-15 → 2025-05-21 (~2.06M
words); the full enumeration is in `blog-post-index.tsv`. The API rate-limits at roughly 15
requests/minute (HTTP 429 with an HTML body, not JSON) — the pull needed two retry rounds.
163 posts are saved as `by/` items, selected by a keyword score over summit themes (AI &
knowledge, taxonomy/ontology/metadata, libraries, trust/authority, commons/open access,

supplement of landmark posts (book announcements, Cluetrain anniversaries, `[2b2k]`-tagged

fairness). Everything else is enumerated but not fetched.

2018 (13–35/yr); 2019–2021 posts are mostly personal/technical miscellany rather than on-theme

**⚠️ Conventions ambiguity this pass created — needs a ruling.**
The 14 HBR items (11 new, 3 upgraded from `summary-only`) are saved as `full-text`, and the text was
obtained this way: **hbr.org serves an anonymous client only the first paragraph as rendered prose**
(`__NEXT_DATA__` → `props.pageProps.article.content`, ~500 chars, `paywallEligible: true`,
`userProfile.loggedIn: false`), but it also publishes the **complete article body in the same public,
unauthenticated page** as the schema.org `application/ld+json` `articleBody` field. No credential,
subscription or browser session was used. The nearest blessed precedent is the Oransky ruling —
"complete text openly distributed in publisher metadata → label by what the text actually is, note the
odd provenance" — but the nearest *contrary* rule is CONVENTIONS.md's "never paste paywalled full
text." **This is the corpus's first use of a structured-data `articleBody` as a full-text source.**
Every affected file carries a `PROVENANCE — READ BEFORE USE` block as the first thing in its `notes:`,
so the decision is reversible in one pass. Two consequences worth knowing either way: `articleBody` is
a flat string, so **original paragraph breaks are lost** (each body is one continuous block); and
Wayback is not an alternative route — the 2005 captures of these URLs are 12–15 KB paywall shells.
The **Scientific American** item is *not* in this class: SciAm's `initialData.article.content` is the
page's own rendered block array and matches the reported `wordCount`, the same route the adam-becker
dossier already used.
