# Cloud Megastructures and Platform Utopias

## Abstract (only openly available portion)

From subterranean cloud computing infrastructure to handheld and embedded interfaces, planetary-scale computation can be understood as an accidental megastructure. Instead of so many different genres of computation spinning off one by one, perhaps they cohere into something like a global Stack, with Cloud, City , and User layers.
