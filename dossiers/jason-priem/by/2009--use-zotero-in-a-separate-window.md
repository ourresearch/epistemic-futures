# Use Zotero in a separate window

## Full text

[![zotero-two-screens1](http://jasonpriem.com/wp-content/uploads/2009/09/zotero-two-screens1.jpg "zotero-two-screens1")](http://jasonpriem.com/wp-content/uploads/2009/09/zotero-two-screens1.jpg)

As I’ve [written before](http://jasonpriem.com/2008/05/zotero-the-least-known-triumph-of-open-source/), I love the free citation manager [Zotero](http://www.zotero.org).   And the group and sharing features that just dropped as part of [v2.0b7](http://www.zotero.org/support/changelog#changes_in_2.0b7_september_15_2009), while still a little buggy, are taking the awesomeness up another level.

But one thing about Zotero has always really annoyed me: the horizantally-split screen.  I never feel like I have enough vertical context for either my Zotero library or the web page I’m viewing.   Meanwhile, I’ve got a whole ‘nother monitor just sitting there empty. Some other folks [have complained](http://forums.zotero.org/discussion/222/sidebar/) about this too, suggesting a sidebar view for Zotero.

Today, though, I realized that there’s a really obvious solution: just open up a new Firefox window (ctrl+n), put it on my other monitor, and display Zotero full-screen there.  Dual-monitor workflow bliss.
