# Hattie’s Table of Effect Sizes

## Full text

[Hattie’s Table of Effect Sizes](<http://www.google.com/url?sa=t&source=web&cd=3&ved=0CCsQFjAC&url=http%3A%2F%2Fwww.geoffpetty.com%2Fdownloads%2FWORD%2FGeoffonHattie.doc&rct=j&q=hattie's%20table%20of%20effect%20sizes&ei=2MxpTquXPKjo0QHliojnBA&usg=AFQjCNEXS_NmsiJ-EAy4cgf-8K83dt9ZxA&sig2=HN7E4llIzCH5SwfnOOyNFQ>)

I need more information to make this table meaningful — and meta-analyses are always tricky things. But I think tables like this (and Hattie is just a follower here of Bloom and others) help people think about prioritizing changes to pedagogy.

What Hattie finds, of course, is unsurprising — feedback rules the roost when it comes to results. What would make this stuff meaningful of course is in-depth descriptions of how each attribute was defined and tested, but I guess for that you need the [book](<http://www.amazon.com/Visible-Learning-Synthesis-Meta-Analyses-Achievement/dp/0415476186/ref=ntt_at_ep_dpt_1>).
