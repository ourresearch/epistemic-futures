- pro-tip: a read-only transaction can create a cycle of dependencies that make a transaction sequence not serializable. #[pgcon](http://search.twitter.com/search?q=%23pgcon) [#](http://twitter.com/selenamarie/statuses/71680675463438336)

- Basic idea: find a cycle in a graph, and break the transaction that caused it to preserve serializability. #[ssi](http://search.twitter.com/search?q=%23ssi) #pgcon #[hopeigotthatright](http://search.twitter.com/search?q=%23hopeigotthatright) [#](http://twitter.com/selenamarie/statuses/71682668546371584)

- SSI rule is: don't let a transaction both have a rw-conflict *in* AND a rw-conflict *out* #[ssi](http://search.twitter.com/search?q=%23ssi) #pgcon [#](http://twitter.com/selenamarie/statuses/71683854028652544)
