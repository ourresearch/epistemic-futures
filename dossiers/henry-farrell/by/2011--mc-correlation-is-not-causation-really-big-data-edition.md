# Correlation is Not Causation – Really Big Data Edition

## Full text

Via Cosma in [comments at the other place I hang out](http://crookedtimber.org/2011/12/11/fun-with-statistics/#comment-391599,) [this](http://www.google.com/trends/correlate/draw) is a very nice teaching tool for the sole and single purpose of getting this point across to students. NB that you need to be logged into a Google ID to use it. My favorite so far is the .8222 correlation between my random graph and searches for “frogsex” (the mind squirbles).
