# Primes!

## Full text

The fundamental theorem of arithmetic is, as the name suggests, pretty fundamental. I built an interactive infographic which does a better job explaining it than I could do using words.

My employer, New Scientist, has reached 100,000 likes on Facebook, and they’ve posted this infographic on their site to their followers to celebrate. Needless to say, I’m enjoying my new job. More on what I’ve been doing over there in the next post!

For those of you interested: I built this largely using D3.js. The source code is available as a gist on GitHub, and you can also view it live on bl.ocks.org.
