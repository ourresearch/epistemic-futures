## Add linked images to PDFs

While working on an internal project, we developed “[pdfstamp](https://www.crossref.org/labs/pdfstamp/)“, a command-line tool that allows one to easily apply linked images to PDFs. We thought some in our community might find it useful and have [released it on github.](http://github.com/Crossref/pdfstamp) Some more PDF-related tools will follow soon.
