## Ubiquity commands for Crossref services

So the other day [Noel O’Boyle](http://baoilleach.blogspot.com/) made me feel guilty when he pinged me and asked about the possibility using one of the Crossref APIs for creating a [Ubiquity](https://wiki.mozilla.org/Labs/Ubiquity) extension. You see, I had played with the idea myself and had not gotten around to doing much about it. This seemed inexcusable- particularly given how easy it is to build such extensions using the API we developed for the [WordPress and Moveable Type plugins](http://sourceforge.net/projects/crossref-cite/) that we [announced](/blog/crossref-citation-plugin-for-wordpress/) earlier in the year. So I dug up my half-finished code, cleaned it up a bit and have [posted the results.](https://www.crossref.org/labs/ubiquity-plugin/)

Note that the back-end that supports the plugins has been moved to more stable machines and the index is now being automatically updated with journal and conference proceeding deposits (sorry, no books yet).

Also note that we are hoping that others will look at the code for the WordPress, Moveable Type and Ubiquity plugins and create more such extensions. If you do, please let us know about them at [citation-plugin@crossref.org](mailto:citation-plugin@crossref.org).
