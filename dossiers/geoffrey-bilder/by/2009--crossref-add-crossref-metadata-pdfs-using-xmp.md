## Add Crossref metadata to PDFs using XMP

In order to encourage publishers and other content producers to embed metadata into their PDFs, we have released an experimental tool called “pdfmark”, This open source tool allows you to add [XMP](http://en.wikipedia.org/wiki/Extensible_Metadata_Platform) metadata to a PDF. What’s really cool, is that if you give the tool a Crossref DOI, it will lookup the metadata in Crossref and then apply said metadata to the PDF. More detail can be found on the [pdfmark page](https://www.crossref.org/labs/pdfmark/) on the [Crossref Labs](https://www.crossref.org/labs/) site. The usual weasels words and excuses about “experiments” apply.
