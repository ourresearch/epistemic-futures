# Gutenkarte:  Geo annotation of Gutenberg texts

## Full text

Another "wow" from [Where 2.0](http://www.oreillynet.com/conferences/blog/where_20/): Schuyler Erle demoed [Gutenkarte](http://www.gutenkarte.org/), a fabulous site that uses [Metacarta](http://www.metacarta.com)'s geo text mining engine to link classic works from Project Gutenberg to accompanying maps. How often have you read a book and wondered about where it took place and how long it might have taken to get from here to there? Schuyler's demo, showing Thucydides' classic [The History of the Peloponnesian Wars](http://www.gutenkarte.org/section/7142/0), accompanied by a map showing the locations mentioned in the text, suggests how useful MetaCarta's technology is in automatically adding geo-annotation to texts.   

Gutenkarte is build in part with [Openlayers.org](http://www.openlayers.org), Metacarta's open source toolkit for associating a map with any web page.
