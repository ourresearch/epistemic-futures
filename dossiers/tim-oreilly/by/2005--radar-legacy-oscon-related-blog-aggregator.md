# OSCON-related blog aggregator

## Full text

Casey West writes: 

> I was sitting in the blogging BOF and there was a lot of talk about O'Reilly Media creating a feed aggregator. People were really interested in a field on registration that requested their blog URL or feed URL. My contention was that if the community wants it, the community should create it. So I [created it](http://oscon.blogdns.org/). So it seems to be working quite well at this point. If you want to mention media outlets at some point, feel free to mention Planet OSCON.
