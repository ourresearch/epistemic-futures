# Flickrcamp

## Full text

Beth Freeman writes: "Foocamp continues to generate [spinoffs](http://www.flickr.com/photos/pinhole/173946493/)...." Beth's right. The [Foo Camp](http://en.wikipedia.org/wiki/Foo_Camp) idea is a powerful one, and [Bar Camp](http://barcamp.org) has really run with it, inspiring many second order derivatives as well, including the proposed [flickrcamp](http://www.flickr.com/photos/pinhole/173946493/). I'm glad. It's great whenever like-minded souls get together to learn from each other.
