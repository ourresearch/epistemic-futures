# The summit's public website, as markdown

Clean captures of the four pages of **https://epistemicfuturessummit.pubpub.org/**, the public
site for the Epistemic Futures Summit (MIT, September 23–24, 2026). Captured 2026-08-15; text is
verbatim from the site with page chrome (nav, search, footer) removed. Headings and list
structure follow the page.

| File | Page |
|---|---|
| [`home.md`](home.md) | `/` — workshop description, dates and location, target outputs, organizers |
| [`attendees.md`](attendees.md) | `/attendees` — organizers + confirmed participants |
| [`schedule.md`](schedule.md) | `/schedule` — Wednesday evening + Thursday program, with session leads |
| [`concept-note.md`](concept-note.md) | `/pub/w1aicj1h` — the concept note ("Workshop Rationale") |

The site is Cloudflare-fronted and refuses non-browser clients; if you want to refresh these,
use a real browser session rather than `curl`.
